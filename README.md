# OUT OF SYNC: PHASE ZERO

**Out of Sync: Phase Zero** — игровой проект на **Godot 4.7.2**, включающий одиночный режим и базовую кооперативную игру.

## О проекте

Это текущая версия проекта, находящаяся в разработке. Проект развивается поэтапно: добавляются игровые механики, интерфейс, сетевые возможности и исправления.

## Кооператив

В проекте предусмотрен базовый сетевой режим.

**Порт по умолчанию:** `1766` (UDP).

### Создание игры

В главном меню выберите:

**КО-ОП // СЕТЕВАЯ ИГРА → СОЗДАТЬ ЛОББИ**

### Подключение к игре

В главном меню выберите:

**КО-ОП // СЕТЕВАЯ ИГРА → ПОДКЛЮЧИТЬСЯ**

После этого укажите IP-адрес компьютера, на котором создано лобби.

Для игры в одной локальной сети можно использовать локальный IP-адрес хоста.

При использовании Radmin VPN хосту и клиенту необходимо использовать соответствующие VPN-адреса. Для устройств, подключаемых через интернет или мобильную сеть, требуется рабочий VPN/туннель, который действительно передаёт UDP-трафик через порт `1766`.

Рекомендуемая платформа:

**Windows x86_64**

Важно:

Для передачи готовой версии другому пользователю можно использовать папку с этими файлами или упаковать её в `.zip`.

## Лаунчер и обновления

Для проекта также разрабатывается отдельный **Out of Sync Launcher**.

Лаунчер предназначен для:

- проверки репозитория и доступных релизов;
- определения установленной версии игры;
- загрузки новых версий;
- установки обновлений;
- запуска игры из установленной папки.

Релизы игры распространяются в виде ZIP-архивов, содержащих необходимые файлы Windows-сборки.

## Использование ИИ

При разработке **Out of Sync: Phase Zero** использовались инструменты искусственного интеллекта.

ИИ применялся как вспомогательный инструмент, в том числе для:

- разработки и рефакторинга отдельных участков кода;
- поиска и исправления ошибок;
- анализа проблем при запуске и экспорте;
- работы над интерфейсом и визуальным оформлением;
- подготовки и редактирования документации;
- поиска вариантов реализации отдельных игровых и технических решений.

ИИ не рассматривается как самостоятельный автор проекта: итоговая структура проекта, решения по реализации, проверка работоспособности и финальная сборка выполняются и контролируются разработчиком.

## Статус

Проект находится в разработке. Функциональность, сетевой режим, интерфейс и система обновлений могут изменяться между версиями.
