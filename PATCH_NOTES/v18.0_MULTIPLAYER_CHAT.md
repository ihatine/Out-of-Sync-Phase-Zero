# PATCH v18.0 // CO-OP + GLOBAL CHAT

- ENet CO-OP is now paired with a global chat available with ENTER or T.
- Chat is server-relayed and visible to all connected players.
- Radmin VPN works through the host's Radmin virtual IPv4 address on UDP port 1766.
- Host creates lobby; clients enter the host's Radmin IP and the same port.
- Player movement replication remains peer-to-peer through the ENet session.
