# v16.5 // STABILITY + SETTINGS + ITEMS

## Предметы
- Подбор предмета больше не перезаписывает занятый слот.
- Если выбранный слот занят, игра ищет первый свободный слот.
- Если все 3 слота заняты, предмет остаётся в мире и не исчезает.
- Переключение предметов не оставляет старые tween-callback, способные скрыть новый предмет.
- Исправлено дублирование ссылки на визуал фонарика.

## Настройки
- Изменения разрешения и режима окна применяются только после «ПРИМЕНИТЬ».
- Громкость, чувствительность, HUD, VSync и графический профиль теперь тоже являются отложенными изменениями.
- «ПО УМОЛЧАНИЮ» меняет только текущий предпросмотр; сохранение происходит после «ПРИМЕНИТЬ».
- «НАЗАД» без применения откатывает настройки к сохранённым.
- Переназначение клавиш применяется только после «ПРИМЕНИТЬ».
- Пробел и физические клавиши считываются через physical_keycode.
- Одинаковые клавиши подсвечиваются красным и получают предупреждение.

## Графика
- LOW / MEDIUM / HIGH реально меняют 3D render scale, MSAA и лимит FPS.
- UI не уменьшается вместе с 3D render scale.
