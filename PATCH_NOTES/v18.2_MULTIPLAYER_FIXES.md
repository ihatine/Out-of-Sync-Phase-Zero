# v1.8.2 — Multiplayer / Chat / Settings Fixes

- Remote players now have visible arms, hands and a flashlight instead of a capsule-only body.
- Remote flashlight state is synchronized.
- Global chat is permanently visible in the upper-right; closing input no longer hides chat history.
- Door transitions are requester-only: only the player who interacts with the door changes scene.
- Added a transition lock to prevent repeated RPC/scene-change spam.
- Settings “По умолчанию” resets only the currently selected tab.
