# Out of Sync v1.9.0 — Character + Chat

- Replaced the remote-player capsule placeholder with a humanoid body: head, hair, torso, hips, legs, boots, sleeves, forearms, palms and fingers.
- Added a proper remote flashlight assembly attached to the right hand.
- Chat now blocks player movement, jump, attack and mouse-look while the input field is active.
- Enter sends the message and restores movement; Escape cancels the input and restores movement.
- Chat remains visible after closing the input field.
- Chat is registered as a global group so the player controller can reliably detect its active state.
