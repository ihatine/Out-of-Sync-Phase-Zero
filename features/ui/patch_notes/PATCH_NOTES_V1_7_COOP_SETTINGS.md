# v1.7 // CO-OP + SETTINGS + MOBILE

- Меню затемнено и смещено выше; добавлены нормальные SVG-иконки.
- Исправлено масштабирование UI: окно больше не должно мылить текст при изменении размера.
- Настройки разрешения и полноэкранного режима теперь применяются только кнопкой «ПРИМЕНИТЬ».
- Чувствительность и громкость показывают проценты.
- Добавлены профили графики: Низкое / Среднее / Высокое. Профиль меняет 3D scale, MSAA и лимит FPS; на мобильных дополнительно ограничивается нагрузка.
- PATCH_NOTES перенесены в `features/ui/patch_notes`; записи раскрываются и листаются.
- Добавлен кооператив через ENet: хост/подключение, до 4 игроков, порт по умолчанию 1766.
- Игроки синхронизируют позицию и поворот.
- Добавлены сенсорные кнопки для движения, взаимодействия, фонаря, атаки и слотов.
- HUD: HP, заряд фонаря, текущий предмет и 3 слота.
- Добавлен тестовый меч с отдельной анимацией удара.
- Фонарик постепенно разряжается и заряжается, когда выключен.
- Переходы через тестовые двери синхронизируются в сетевой игре.
