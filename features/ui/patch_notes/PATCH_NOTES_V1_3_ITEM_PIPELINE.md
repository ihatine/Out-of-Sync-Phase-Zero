# v1.3 // ITEM PIPELINE

- Исправлен процедурный viewmodel bob с явной типизацией `float`.
- Предметный pipeline переведён на `ItemData` вместо отдельной логики только для палки.
- Поднятие: физический предмет -> `equip_item()` -> хват в правой руке.
- При поднятом предмете фонарик автоматически переносится в левую руку.
- Q убирает текущий предмет в слот, фонарик возвращается в правую руку.
- G физически выбрасывает предмет перед игроком с импульсом.
- 1/2/3 переключают инвентарные слоты.
- Атака и анимация хвата используют параметры текущего `ItemData`.
- Убрано создание Transform3D до добавления dropped-item в дерево.
