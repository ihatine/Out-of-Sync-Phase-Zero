# UI / Hands / Flashlight — v1.1

## Настройки
- Пересобран экран настроек в трёхколоночную компоновку: навигация слева, основные параметры по центру, качество и предпросмотр справа.
- Увеличены безопасные размеры панели и расстояния между контролами.
- Добавлены параметры «Размытие в движении» и «Зернистость».
- Добавлена расширенная группа качества: тени, текстуры, эффекты, постобработка, дистанция прорисовки, анизотропная фильтрация.
- Сохранение настроек расширено новыми параметрами.

## Руки и фонарь
- Добавлена отдельная левая рука и левый фонарь.
- Луч фонаря теперь физически переключается между правой и левой рукой.
- Добавлена более читаемая кисть/большой палец в view-model.
- F переключает фонарь.

## Предметы
- При подборе палки фонарь автоматически переходит в левую руку.
- Q убирает предмет, фонарь возвращается в правую руку.
- G выбрасывает предмет перед игроком; его можно снова подобрать через E.
- Исправлена загрузка пользовательских биндов при запуске игрока.
